## AI usage
In the current era of computer science, I consider it important and fundamental to explain how I use AI in my projects.
**How I use AI:**
* To explain or develop concepts I don't understand at first in a way that I can use to learn more efficiently said things. I will for example ask it to give me examples unrelated to my problems or needs and will try to implement it in my code by myself.
* To help me find bugs if I don't find them myself (only if really can't find where it comes from and only for small bugs.. If I see that AI don't find where the problem is after a few minutes I go back to searching by myself).. Usually a missing semicolon for example
* To have suggestions on how to make my code better
 
**How I don't use AI:**
* To generate code : All the lines in my projects are hand-written. 
* To do things I don't already know how to do
* To find an information I can find in the documentation : I can do it myself!
* I don't trust AI for high-stakes decisions (i.e. architecture, security) : I'd rather ask important questions to a human I know I can trust.
